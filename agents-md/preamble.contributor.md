# Contributing to Neo.mjs — what your agent should know first

Audience: `contributor`. This is on-demand guidance for an outside contributor and their agent.
Printing it does not configure your harness or load an instruction file. The workflow links below
use this declared audience; they need no private Neo tools or accounts.

This is not the setup guide. It is the shorter thing beside this repository's own contributor
documentation: enough of how the codebase thinks that your first change reads like the rest of it.
