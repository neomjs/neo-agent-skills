# Contributing to Neo.mjs — what your agent should know first

Your harness read this file because it is this repository's agent-instruction file. Nothing here was
configured for you, and nothing here needs an account, a container or a model provider.

`CONTRIBUTING.md` has the setup loop and the pull-request rules. This is the shorter thing beside it:
enough of how the codebase thinks that your first change reads like the rest of it.
