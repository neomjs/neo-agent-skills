## §pr_diff_equals_pr_body
Your pull-request body is read as carefully as your diff, so write it for a reviewer who has not
been following along: what changed, why, and what you ran to check it. Link the issue rather than
restating it, and say the same thing in fewer words wherever you can — a short body that names its
evidence is worth more here than a long one that narrates the diff back.

The same applies inside the code. If a change needs more comment lines than code lines to explain
itself, the explanation belongs in the commit message.
