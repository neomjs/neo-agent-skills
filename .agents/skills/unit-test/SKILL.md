# Unit Test Workflow
Before writing, modifying, fixing, or explicitly running unit tests, read and follow `.agents/skills/unit-test/references/unit-test.md` (standard Playwright patterns will fail). Review-only placement/idiom audits stay under `pr-review` and do not activate this workflow.
