# Design authority — a ticket that calls an existing behavior wrong

A receipt — geometry, timing, a rendered frame — shows what happens, never whether it is wanted. When a ticket calls an existing behavior wrong and there is no crash, no red and no contradiction with the surface's own JSDoc, its Architectural Reality carries `Design authority: <the record sentence, quoted>` — the ADR section, guide or owning JSDoc that made the behavior intended — before The Fix is written. Search the decision-record directory, the guides and `ask_knowledge_base`. Nothing found → `Design authority: none found (searched: …)` and a fork on the owning record (its epic, or a Discussion), not a Fix.

Reviewers read the line as the premise: `pr-review` §9.0.
