# Design authority — non-epic agent tickets

A receipt — geometry, timing, a rendered frame — shows what happens, never whether it is wanted. Every non-epic agent ticket without a defect excuse (fenced error, spec path or failing test in Problem/Context, or quoted `@`-JSDoc) carries in The Architectural Reality before The Fix:

- `Design authority: <the record sentence, quoted>` — ADR, guide or owning JSDoc making the behavior intended.
- `Design authority: none found (searched: …)` — searched decisions, guides and `ask_knowledge_base`; fork on the owning record, not a Fix.
- `Design authority: n/a — <reason>` — calls no existing behavior wrong.

Reviewers read the line as the premise: `pr-review` §9.0.
